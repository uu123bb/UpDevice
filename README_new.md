## Sleepy 是什么？

Sleepy 是一个提供网页服务的 Flask 应用，可将站主所上传的设备当前状态~~公之于众~~

想要搭建 Sleepy？请参阅[这个项目](https://github.com/sleepy-project/sleepy)，或者你想在 *Vercel* 等无持久磁盘的平台上搭建的话，可以参阅[我的Fork](https://github.com/uu123bb/sleepy_serverless)（修改部分也是 Vibe Coding）
